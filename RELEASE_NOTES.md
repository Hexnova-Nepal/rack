## What's new in Rack 1.1

**Times your games wherever you start them.** Rack stays in the tray and notices any game from your library, even one started from Steam, a desktop shortcut or the Start menu. It no longer starts PowerShell in the background to do this, so it costs almost nothing while you play. While a game runs, Rack can close its window to free memory, and it comes back when you stop.

**Finds new games on its own.** It watches your stores and scan folders, adds new store games, and lists new folder finds under "New games found" for you to review. A first-run screen finds everything in one click.

**More stores.** Ubisoft Connect, EA app, Battle.net and Xbox app games are found automatically, alongside Steam, Epic and GOG. With a free Steam Web API key, Rack also shows the Steam games you own but haven't installed, each with an Install button.

**Right-click everything.** Games, selections, collections and the rack all have menus: play, other ways to start, favourite, status, collections, open folder, desktop shortcut, find a cover, back up saves, hide, uninstall, remove. Text boxes get Cut, Copy and Paste.

**Library tools.**
- "Jump back in" row and a "Now playing" bar
- Play status (Playing, Backlog, Completed, Dropped)
- Automatic lists, such as "Never played"
- Filters, list view and cover sizes
- Hidden games
- Select several games with Ctrl or Shift + click
- Arrow keys to move, Enter to play
- Genres and release years from Steam

**Shortcuts.** Desktop shortcuts and the taskbar's recent games start games through Rack, so their time is counted.

**Save backups.** Rack can back up and restore game saves with Ludusavi, which it downloads for you, and can back up automatically after you play.

**Library backup.** Save your whole library and covers to one file, and restore from it.

**Looks.**
- New default type: Archivo Expanded titles with Geist text
- Four more font choices
- Seven accent colours, or one you pick yourself
- Four dark and three light background shades

**Updates.** The installed version updates itself from GitHub Releases. The portable version tells you when a new version is out.

**Fixes.** "Add game" works again. Games that need administrator rights start properly. ROM names no longer keep their file extension.
